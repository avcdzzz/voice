# 🎙️ Velvet Voice — Studio TTS Engine & AI Voices

A premium, open-source Text-to-Speech studio supporting **Deepgram Aura AI Neural Voices** (Studio HD quality) and **Browser Web Speech API**.

---

## ✨ Features

- **Deepgram Aura AI Engine (Studio HD)**:
  - 12 hyper-realistic human AI voices (Asteria, Luna, Stella, Athena, Hera, Orion, Arcas, Perseus, Angus, Orpheus, Helios, Zeus).
  - Generates true MP3 audio files with 1-click downloads.
  - Real-time Web Audio API frequency spectrum waveform visualizer.
  - API Key input box with automatic `localStorage` persistence.
- **Enhanced Browser Web Speech Engine (Free & Native)**:
  - Intelligently deduplicates system voices across profiles so cards don't play identical fallback voices.
  - Includes a **Direct OS System Voice Dropdown** to directly choose any voice installed on your system (Siri, Alex, Samantha, Daniel, Karen, etc.).
- **Tone & Emotion Presets**:
  - Neutral, Story, Warm, Dramatic, Calm, Newscast, Intense.
- **Playback Controls**:
  - Real-time Speed, Pitch, and Volume fine-tuning.
- **Keyboard Shortcuts**:
  - `Ctrl+Enter` (or `Cmd+Enter`) to speak, `Space` to pause/resume, `Escape` to stop.

---

## 🚀 Quick Start

### 1. Open locally
Simply open `index.html` in Chrome, Safari, Edge, or Firefox.

### 2. Serve locally
```bash
python3 -m http.server 8080
# then open http://localhost:8080
```
